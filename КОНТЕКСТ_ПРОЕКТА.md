## 😣 Боли аудитории (5 штук, порядок принципиален)

Дуга от **операционного → к глубинному личному**:

### 1. Бизнес-операционная
**Заголовок:** Все решения – на мне, команда не тянет  
**Текст:** Делегировать некому, сам делаешь за всех, стратегия вытеснена текучкой. А люди уходят – и новых не найти. Найдём, где система сломана, и выстроим команду, которая работает без тебя.

### 2. Стратегическая / технологическая
**Заголовок:** Надо что-то делать с ИИ – но что  
**Текст:** Давление есть, хайпа вокруг много, а рядом нет человека, который объяснит без лишнего шума. Поймём, где ИИ даст реальный результат именно в твоей компании – и с чего начать без риска.

### 3. Ситуативная (релоканты)
**Заголовок:** Переехал – и строю авторитет заново  
**Текст:** Варшава, Лимасол, Дубай, Берлин – ты профессионал, но здесь тебя никто не знает. Правила игры другие, ожидания другие. Разберём, как встроиться в новый контекст и снова стать тем, кем ты являешься.

### 4. Эмоциональная
**Заголовок:** Устал держать всё в себе  
**Текст:** Сверху давят, снизу требуют, а поговорить по-настоящему – не с кем. Совет директоров ждёт уверенности, команда ждёт ответов. Здесь можно думать вслух – без последствий и без необходимости выглядеть сильным.

### 5. Экзистенциальная (кульминация)
**Заголовок:** Не понимаю, кто я за пределами своей роли  
**Текст:** Карьера выстроена, должность есть – а смысла всё меньше. Вопросы «зачем всё это» не вписываются в корпоративный контекст, и задать их некому. Разберём, что за этим стоит – и куда двигаться дальше.

## 📦 Форматы работы (3 формата)

### 1. Разовая консультация
- 1–2 сессии по 60 минут
- Включает: разбор ситуации, практические рекомендации, материалы, неделя чат-поддержки
- **Цена: 150 €** за сессию (≈ 160 USD)
- Оплата: 100% предоплата

### 2. Сопровождение руководителей

**Спринт** (1 месяц):
- 4 сессии по 60 минут
- Диагностика, постановка целей, домашние задания, follow-up, чат-поддержка
- **Цена: 550 €** (≈ 590 USD) · 100% предоплата

**Интенсив** (2 месяца):
- 8 сессий по 60 минут
- Расширенная диагностика, индивидуальный план развития, плотная обратная связь
- **Цена: 900 €** (≈ 960 USD) · Оплата 50/50 (начало и середина)

### 3. Фракционный CPO / Advisor
- Внешний C-level партнёр собственника по человеческой стороне эффективности бизнеса
- Регулярная работа на стыке решений собственника, поведения команды и people-системы
- Диагностика разрывов в управлении, настройка people-системы под бизнес-цели, включение в сложные кейсы команды
- Формат и стоимость определяются после вводной встречи

## 🎨 Дизайн сайта

**Файл:** `index.html` – одностраничный сайт, всё в одном файле (HTML + CSS + JS)

**Цветовая палитра:** Холодная, строгая
```css
--cream: #F2F4F7       /* фон */
--warm: #E4E9F0        /* тёплый фон */
--sand: #B0BCCC        /* акцентный серый */
--espresso: #1A2535    /* тёмно-синий (основной тёмный) */
--charcoal: #0F1820    /* почти чёрный */
--gold: #4A7FA5        /* синий акцент */
--gold-light: #6A9BBF  /* светлый синий акцент */
--text-muted: #4A5C70  /* приглушённый текст */
```

**Шрифты** (Google Fonts, подключены в `<head>`):
- Заголовки: `Cormorant Garamond` (serif, элегантный)
- Текст: `Jost` (sans-serif, современный)

**Иконки:** Inline SVG (stroke, без заливки)

## 🖼 Как добавить фото

В файле `index.html` найти два места:

**1. Hero (правая половина):**
```html
<div class="hero-right">
  <!-- заменить этот div на: -->
  <img src="photo-hero.jpg" style="width:100%;height:100%;object-fit:cover;object-position:top" alt="Алёна Вербицкая">
```

**2. О менторе:**
```html
<div class="about-img">
  <!-- внутри добавить: -->
  <img src="photo-about.jpg" style="width:100%;height:100%;object-fit:cover" alt="Алёна Вербицкая">
```

Фото должно быть вертикальным (портретная ориентация), минимум 800×1000px.
